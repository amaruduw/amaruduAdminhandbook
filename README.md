🎯 Overview
The Amarudu Handbook is a complete certification preparation resource for aspiring Salesforce Administrators. It covers all topics from the Salesforce Administrator Certification exam with:
13 comprehensive parts covering beginner to advanced topics
Real-world examples and scenarios
Step-by-step implementation guides
Knowledge checks at the end of each section
Interactive Q&A for interview preparation
Capstone project for hands-on practice

🚀 Installation
Option 1: Direct Download
Download all files (index.html, styles.css, script.js)
Open index.html in any modern web browser
No server required - runs locally!
Option 2: Clone Repository
bash
Copy
git clone <repository-url>
cd amarudu-handbook
# Open index.html in browser
Option 3: Local Server (Recommended for Development)
bash
Copy
# Using Python 3
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Using PHP
php -S localhost:8000
Then navigate to http://localhost:8000
